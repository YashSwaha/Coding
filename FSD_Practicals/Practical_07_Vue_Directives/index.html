Vue.js 3 Custom Directives

1. Directive: v-uppercase

Transforms the element's text to UPPERCASE when clicked.

👉 click this text to convert it to uppercase!

Registered via app.directive('uppercase', { mounted(el) { ... } })

2. Directive: v-dynamic-list

Renders and updates a list DOM structure dynamically through a custom directive.

    The custom directive listens to binding changes and dynamically appends <li> elements.
