2. Instructions to Install Node.js

  1. Visit the official website: https://nodejs.org
  2. Download the LTS (Long Term Support) installer for your OS (Windows, Mac, or Linux).
  3. Run the installer and follow standard on-screen prompts.
  4. Open your command prompt or terminal and verify installation by running: 
    node -v
npm -v

3. Running Terminal Scripts in this Practical
