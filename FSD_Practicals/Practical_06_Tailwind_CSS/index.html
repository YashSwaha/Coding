Note on Tailwind Play CDN:

The browser CDN (https://cdn.tailwindcss.com) compiles utility classes dynamically in the client's browser. It is intended strictly for rapid prototyping, development, and classroom demonstrations, not for production deployment.

Tailwind CSS Basics

Tailwind CSS is a utility-first CSS framework packed with classes like flex, pt-4, and text-center that can be composed to build any design directly in your markup.
