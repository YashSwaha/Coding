Simple To-Do List

Demonstrating JavaScript array of JSON-style objects with localStorage persistence.

    Important Concept:
    Browser localStorage saves data as key-value string pairs directly inside the client's browser engine. It persists across reloads on this machine only.
    In contrast, a JSON file stored on a server (e.g., tasks.json managed by Node.js) resides on the backend host and can be accessed, shared, and queried concurrently by multiple client sessions.
