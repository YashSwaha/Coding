Concepts Demonstrated

1. Viewport Meta Tag: <meta name="viewport" content="width=device-width, initial-scale=1.0"> sets viewport width to device width to prevent mobile scaling glitches.
2. Responsive Text (vw unit): Main title uses font-size: 5vw;. 5vw equals 5% of the viewport width.
3. Media Queries: On desktop, columns display side-by-side. When screen width is ≤ 600px, @media (max-width: 600px) switches to a stacked vertical column layout.
