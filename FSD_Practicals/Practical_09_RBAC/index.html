⚠️ Important Educational Concept:
This demonstration implements client-side RBAC using JavaScript DOM manipulation. In production, frontend-only role checks are NOT secure because a user can open browser developer tools and easily modify client variables or unhide HTML elements.
A secure application must always enforce authentication (e.g. Session cookies / JWT) and authorization checks on the backend server for every API request and database query.
